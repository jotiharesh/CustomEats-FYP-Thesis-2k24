# 🍽️ CustomEats: Crafting Your Ideal Dish

## 📌 Overview

**CustomEats** is a food customization mobile application developed as a Final Year Project for BS Computer Science at Isra University Hyderabad.

The application allows users to personalize their meals based on:

* Ingredients
* Spice levels
* Dietary restrictions
* Cultural & religious preferences (e.g., Halal, Vegetarian)

It aims to bridge the gap between customer expectations and the limited customization offered by existing food ordering systems.

---

## 🎯 Problem Statement

Existing food ordering applications provide limited or unclear customization options, making it difficult for users to:

* Avoid unwanted ingredients
* Follow dietary restrictions
* Maintain cultural or religious food preferences

---

## 💡 Proposed Solution

CustomEats enables:

* Full ingredient-level customization
* Adjustable spice levels
* Transparent ingredient details
* Improved communication between customer and kitchen

---

## 🧩 Key Features

### 👤 Customer Interface

* Browse menu
* Customize meals (ingredients, spice level)
* Add to cart
* Place orders
* Track order status

### 👨‍🍳 Chef Interface

* View incoming orders
* Access customization details
* Update order status

### 🛠️ Admin Interface

* Manage menu items
* Monitor orders
* Manage staff

## 🏗️ System Architecture

The system follows a client-server architecture:

* Flutter App → API → Django Backend → MySQL Database

---

## 📊 Research & Findings

A survey conducted during development revealed:

* 78% users prefer customizable food apps
* 73% struggle with dietary restrictions
* 63% avoid ordering due to unwanted ingredients

---

## 🚧 Limitations

* No delivery system (yet)
* Limited to dine-in tablet usage
* No live deployment
* No review/feedback system
